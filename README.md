# 🏰 Reino Defense

Jogo estilo **Tower Defense** desenvolvido com **Flutter + Flame Engine**, inspirado em clássicos de estratégia mobile.

## 🎮 Sobre o Projeto

No Reino Defense, o jogador precisa proteger o castelo contra ondas de inimigos construindo torres estrategicamente pelo mapa.

Este projeto foi criado com foco em aprendizado prático de:

- Desenvolvimento Mobile
- Game Development 2D
- Lógica de Programação
- Estruturação de Projetos
- Versionamento com Git/GitHub

---

## 🚀 Funcionalidades

✅ Inimigos andando pelo mapa  
✅ Torres automáticas que atacam  
✅ Sistema de projéteis  
✅ Vida dos inimigos  
✅ Sistema de moedas  
✅ Vida do castelo  
✅ Game Over  
✅ Reinício da partida  
✅ Construção de torres ao clicar
